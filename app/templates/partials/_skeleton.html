{# ───────────────────────────────────────────────────────────────────────────── Shared skeleton-loading system. Include once in on every page (base.html covers all base-extending pages; standalone pages include it directly). CSS classes are theme-neutral (literal rgba on the dark surface) so they work regardless of each page's own :root variables. JS builders (window.Skeleton) return ready-to-inject markup: Skeleton.cards(n) → n stacked card placeholders Skeleton.table(rows,cols) → a table placeholder in a bordered wrap Skeleton.list(n) → n compact list-row placeholders Skeleton.lines(n) → n text-line placeholders For server-rendered initial states, use the .skel-* classes directly in HTML. ──────────────────────────────────────────────────────────────────────────── #}
